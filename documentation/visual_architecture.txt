## digital pdf

- PyMuPDF 提取原始 spans / chars

#### 1. 全局样式分布基线（Global Baseline Profiling）
对于合规系统生成的单据或合同，其排版系统（Typography System）熵值极低：
* **构建直方图：** 统计整页所有 Span 的 `(font_name, font_size, font_color)` 三元组频次。
* 正常文档的正文字号通常呈**强尖峰分布**（例如 90% 的 Span 集中在 `9.5pt`，少数标题在 `14pt`）。
* 颜色通常收敛于固定的几个枚举值（如 `#000000` 或某固定的灰色 `#333333`）。
* **异常判定：**
如果某个数值字段的 Span，其 `font_size` 属于整页唯一的孤立浮点数（例如其他都是 `10.0pt`，只有它由于编辑器手动缩放变成了 `9.82pt`），或者颜色产生了细微偏差（例如全篇黑色是 `(0, 0, 0)`，只有它是从外部复制带来的 `(15, 15, 15)`），直接被高斯分布或 DBSCAN 判定为离群异常点。

#### 2. Span / Line / Block 几何占比与碎裂度检测（Fragmentation Ratio）
正如你提到的这两个比值，它们是捕获“局部文字微调”的最佳指标：
$$\text{Ratio}_{\text{span\_to\_line}} = \frac{\text{Width}(\text{Span})}{\text{Width}(\text{Line})}, \quad \text{Ratio}_{\text{line\_to\_block}} = \frac{\text{Height}(\text{Line})}{\text{Height}(\text{Block})}$$
* **孤立微型 Span（Micro-Span Injection）：**
* 正常机器生成的文本行，整行通常由 1 个或极少数因中英文切换产生的 Span 构成。
* 若某一行包含 5 个字符，却被切成了 3 个 Span，且其中某个 Span 的 `len(span["chars"]) == 1`（单字符孤立），同时：
$$\text{Ratio}_{\text{span\_to\_line}} < 0.15$$
* 这种极小的占比表明**有人在该行文字的中间挖孔插入或替换了字符**。

#### 3. 字符间距与步进方差（Inter-Character Delta Variance）
* 正常印刷体数字（如西文中的 Tabular Figures / 等宽数字）：
连续数字字符的 X 轴步进距离 $\Delta x_i = \text{origin}[0]_{i+1} - \text{origin}[0]_i$ 应该保持严格的一致性（方差 $\sigma^2 \to 0$）。
* 当插入篡改数字时，造假者无法做到像素级等距对齐：
* 计算关键字段（如金额、日期）中字符序列间距的**变异系数（Coefficient of Variation, $CV = \frac{\sigma}{\mu}$）**。
* 一旦发现某段紧凑数字串的 $CV$ 突变偏高，表明字符在排版几何上被人工位移扰动过。

#### 4. bbox overlap / copy-move detection
Detector	检测内容	产出类型
Occlusion Detector	A covers B（覆盖率、Z 顺序、对象类型）	PDF_OBJECT_OCCLUSION
Object Reuse Detector	A ≈ B（精确/近似/视觉对应）	PDF_OBJECT_REUSE
Overlay Characterization	Overlay 的类型（image/text/vector/form）和不透明度	PDF_OVERLAY_CHARACTERIZATION
Correlation Engine	将上述三者关联	PDF_COPY_MOVE_CORRELATION

#### 5. partial outlining
文本行异常gap，page.get_drawing()
正常表格的 Drawing 都是大矩形、横线、竖线（由简单的 l 划线或 re 矩形指令构成）。 
字符转曲生成的 Drawing，必然包含大量的紧密三次贝塞尔曲线段（包含多个 c 操作符）与环状闭合路径，且外接矩形的长宽比完全符合字符特征。 
一旦在文本行的空白间隙中捕捉到“字符尺寸的高密度闭合曲线群”，立即判定为转曲注入篡改。

#### 6. vector spoofing
检测算法：
​遍历 page.get_drawings()，筛选出所有极小尺寸的矢量元素（比如高度或宽度小于当前正文字号，例如 < 5\text{pt} 的线段或微型闭合块）。
​排除掉合规的下划线（下划线通常横跨整个 Span，宽度较长）。
​将这些微型矢量图元与所有的字符 char["bbox"] 做空间相交（Intersection）测试。
​判定： 如果一个微小的无描边填充矩形/线段，正好跨越并压在某个字符（如 'F'、'3'）的关键几何边缘上，直接告警提示“检测到人工矢量笔画干预与文本修补”。

2. text block profile
对于所有text blocks内部:
- baseline anomaly detection
对于paragraph region里的text blocks:
- y坐标接近的bbox放在一起，每个bbox都有average baseline gradient，用z score via MAD对比
对于table region里的text block:
- 以列为单位，为列内bbox找left alignment / right alignment / centre alignment对齐线 (需判断主对齐线来做基准)，列内bbox的起始端、中点、尾端x坐标对比，z-score anomaly via MAD。行内直接测中线。

#### 步骤 1：提取当前列内所有 $N$ 个 bbox 的三个一维投影
设当前列有 $N$ 个单元格，对于第 $i$ 个数字的 BBox，提取：
* 左端坐标：$L_i = x_{\text{min}}^{(i)}$
* 中心坐标：$M_i = \frac{x_{\text{min}}^{(i)} + x_{\text{max}}^{(i)}}{2}$
* 右端坐标：$R_i = x_{\text{max}}^{(i)}$

#### 步骤 2：用鲁棒离散度（MAD）自动识别这一列的“主排版法则”
计算这三个坐标序列的绝对中位差（MAD）：
$$\text{MAD}_L = \text{median}(\vert{}L_i - \tilde{L}\vert{})$$
$$\text{MAD}_M = \text{median}(\vert{}M_i - \tilde{M}\vert{})$$
$$\text{MAD}_R = \text{median}(\vert{}R_i - \tilde{R}\vert{})$$
* **判定主对齐模式**：
$$\text{Mode} = \arg\min(\text{MAD}_L, \text{MAD}_M, \text{MAD}_R)$$
* 如果 $\text{MAD}_L$ 最小（接近 0），说明此列排版法则是**左对齐**，主基准为 $L$；
* 如果 $\text{MAD}_M$ 最小，说明此列排版法则是**居中对齐**，主基准为 $M$；
* 如果 $\text{MAD}_R$ 最小，说明此列排版法则是**右对齐**，主基准为 $R$。

#### 步骤 3：在选定的主基准轴上，运行 Modified Z-score
选定主基准序列 $A \in \{L, M, R\}$ 后，只对序列 $A$ 跑前面提到的修正 Z-Score：
$$S_i = \frac{0.6745 \cdot \vert{}A_i - \tilde{A}\vert{}}{\max(\text{MAD}_A, 0.5\text{ px})}$$
* **定罪判决**：如果某个单元格的 $S_i > 3.5$（或偏移绝对距离 $> 2\sim 3\text{ px}$），直接报出：**“该字符破坏了该列的主排版对齐基准”**。
